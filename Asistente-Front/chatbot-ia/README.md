# chatbot-ia

Interfaz de chat en React + Vite para el asistente IA. Envía las preguntas del usuario al backend Node (`POST /api/consultar`) y muestra la respuesta generada a partir del corpus indexado.

Ver el [README principal](../../README.md) para la arquitectura completa, variables de entorno y pasos de instalación.

## Desarrollo

```bash
npm install
npm run dev
```
